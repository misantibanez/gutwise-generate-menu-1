# Gutwise Generate Menu

A simple Python-based Azure Function that generates menu items (or menus) programmatically. Useful for dynamically building menus from data, templates, or other inputs.

- Minimal dependencies (Python)

- Azure Functions Core Tools (for local development)  
- Azure account (if deploying to Azure)
